# Paper Mountain · 论文山区地图

Paper Mountain 是一个**数据驱动的三维研究领域地图前端框架**。它把子领域表现为相连的山体，把论文放在所属地块上，并用引用关系影响论文之间的平面距离。点击一篇论文即可查看它引用了谁、又被谁引用。

当前版本为 **v1.1 空壳框架**：仅包含 2 个通用子领域、4 篇占位论文和 2 条占位引用关系。项目不包含真实论文数据，也不对论文质量作自动判断。

## 本地入口

双击打开 [paper-mountain/index.html](paper-mountain/index.html) 即可查看，无需账号、后端或构建步骤。页面通过 importmap 从公共 CDN 加载 `three@0.157.0`，首次打开需要能访问该 CDN。

如果浏览器限制直接打开本地文件，也可在 `paper-mountain` 目录运行：

```bash
python -m http.server 8765
```

随后访问 [http://localhost:8765](http://localhost:8765)。本地服务器同样无需登录。

## 主要功能

- **三维地形**：基于平滑噪声、子领域高斯抬升、山脊连接和边缘下沉生成连绵缓丘；按子领域色相和海拔为顶点着色。
- **论文布局**：先在所属子领域附近放置论文，再用节点斥力、引用引力和子领域中心引力迭代计算位置。布局逻辑独立放在 `layout.js`。
- **引用探索**：默认隐藏连线；选中论文后，青色显示“本文引用了”，金色显示“被其他论文引用”。右侧列表可继续跳转到关联论文。
- **地图交互**：支持拖拽旋转、滚轮缩放、悬停提示、点击选中、相机飞行、自动旋转和重置视角。
- **论文详情**：显示完整标题、来源与年份、状态、海拔、原文链接、核心思路、留下的问题，以及引用与被引用列表。网页链接在新标签页打开；本地路径可复制。
- **搜索与添加**：搜索标题、简称、来源和研究问题时，未匹配点位变暗；可临时添加论文标点并播放弹出动画。

## 替换研究领域数据

只需编辑 [paper-mountain/src/data.js](paper-mountain/src/data.js) 中的三个数组：

| 数组 | 用途 |
| --- | --- |
| `CLUSTERS` | 子领域名称、颜色、中心坐标、峰高和影响半径 |
| `PAPERS` | 论文信息、所属子领域、海拔和状态 |
| `EDGES` | 引用关系；`[sourceId, targetId]` 表示 `sourceId` 引用了 `targetId` |

论文的 `cluster` 必须引用现有 `Cluster.id`，每条引用边中的两个 ID 也必须存在于 `PAPERS`。页面启动时会检查这些关系并提示数据错误。

```text
paper-mountain/
├── index.html
├── style.css
└── src/
    ├── data.js          # 唯一需要替换的占位数据
    ├── terrain.js       # 地形高度、噪声与顶点颜色
    ├── layout.js        # 力导向论文布局
    ├── papers.js        # 论文球体、光晕与动画
    ├── connections.js   # 选中后的引用连线
    ├── camera.js        # 相机、拖拽、缩放与飞行
    ├── panel.js         # 概览、详情与链接
    ├── modal.js         # 添加论文表单
    └── main.js          # Three.js 场景与交互装配
```

为了同时支持本地文件直接打开和拆分的数据文件，页面用普通脚本装载各功能文件，并通过 importmap 动态导入 Three.js 的 ES Module；无需打包器。

## 当前边界

- 所有数据都在前端；没有后端、论文抓取或自动定位服务。
- 添加论文只在当前页面会话中有效，刷新后恢复占位数据。
- `elevation` 是输入数据中的相对前沿标注，**不是引用量或论文质量评分**。
- 当前每篇论文只有一个主子领域；真实场景中的跨领域归属、证据置信度和随时间变化的前沿判断尚未实现。
- `demo/` 保留上一版界面原型；`paper-mountain/` 是本次通用框架的本地入口。
