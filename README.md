# Paper Mapper

用可交互的三维地形理解一个研究领域：平面位置表示研究问题与子方向，海拔表示同一问题、同一时间切片中的相对前沿位置，连线表示论文之间的承接关系。

## 前端演示

打开 [`demo/dist/index.html`](demo/dist/index.html) 即可使用，无需安装依赖。演示包含五个研究分区和 18 篇**虚构论文**，支持旋转、缩放、搜索、时间切片、查看研究脉络，以及添加新的模拟标点。新增论文只保存在当前浏览器的 `localStorage` 中。

## 坐标模型

- **X / Z：研究问题。** 相邻位置表示主题接近，分区不是互斥的；当前演示为简化，每篇论文只归入一个主分区。
- **Y：相对前沿位置。** 演示先为论文设定进展指数，再以该分区截至所选年份的最高指数归一化。高度不是论文质量或引用量评分；真实系统还需要按具体研究问题细分。
- **路径：论文关系。** 标出前置工作和后续工作。演示关系也是虚构数据。
- **迷雾：判断的不确定性。** 接入真实论文时，需要把原文证据、人工确认和自动推断区分开，并标记未解决问题的后续状态。

下一阶段可以加入论文解析、问题归类、关系证据与人工校正流程；当前版本仅提供前端界面与交互。
